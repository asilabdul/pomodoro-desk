# Pomodoro Desk

A calm Next.js focus timer that stays entirely in the browser.

## Run

```bash
npm install
npm run dev
```

## Features

- 25 / 5 / 15 defaults, editable in Settings
- Space to start or pause, Skip to jump ahead
- Optional chime and desktop notification
- Local stats, JSON export, daily goal of 8 focus blocks
- Installable via the web app manifest
